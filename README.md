# Baby Jeopardy

A one-board Jeopardy game for a baby celebration. Host it on GitHub Pages.

## Play

Open the GitHub Pages URL, or open `index.html` in a browser.

- Click a dollar tile to open a question
- **Space** hides the question if someone buzzes in early
- **Enter** reveals the answer
- **Esc** closes the card

## Hvem er hvem? photos

The last category shows a photo as the question, then the same photo plus the name on reveal.

Replace the placeholder files in `photos/hvem/` with real pictures, using the same names:

- `lilo.svg` → Lilo
- `w.svg` → W
- `n.svg` → N
- `nico.svg` → Nico
- `nina.svg` → Nina

JPG or PNG is fine — just keep the filename, or change the photo path in **Edit Questions**.
